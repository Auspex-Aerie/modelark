# ModelArk v0.3.1 — Public Alpha Patch

ModelArk v0.3.1 is an application-only patch over the schema-v7 v0.3.0 release. It gives the
post-v0.3.0 Fill evidence fixes their own package and runtime identity so an operator can distinguish
the installed artifact with `modelark --version` as well as its retained commit and digest.

## What changed

- Fill cards compare new planned work with the remaining writable budget.
- Archived occupancy is shown separately against nominal device capacity.
- Lost/excluded plan members remain visible but are plainly marked unavailable.
- Live archive occupancy uses per-drive generations and response-consistent terminal recovery,
  preventing stale cross-drive updates from being presented as current evidence.

## Upgrade from v0.3.0

No catalog migration is required. Stop the current service, retain its unit and runtime as rollback,
deploy v0.3.1 against the same explicit data/state/config paths, and start without automatic Fill
resume. Then confirm the proposal, plan, Drives, and idle Fill state before taking another action.

Approval and execution remain separate. Installing or starting v0.3.1 does not approve a proposal,
start Fill, attach a drive, or move archive bytes.

For fresh installation and the earlier pre-v7 migration boundary, use the linked guides in the
[README](../../README.md) and [upgrade guide](../upgrading.md).

Usable Slice, scratch delivery, and peer-to-peer transport remain future direction rather than
features of this patch.
